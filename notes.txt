Git Notes
=========

Git is a version control system.
Git helps track changes in files.
Git makes collaboration easier.

Basic Workflow:
1. Modify files
2. Stage changes (git add)
3. Commit changes (git commit)

Useful Git Commands:
-------------------
git init - creates a new repository
git add - stages changes
git commit - saves changes
git status - shows current state
git log - shows commit history


Branching:
---------
git branch - lists branches
git switch -c - creates and switches to new branch
git switch - switches branches


Merging:
-------
git merge - combines branches
git merge --no-ff - creates merge commit


Remote Repositories:
-------------------
git remote add origin <url> - connects to remote
git push - sends commits to remote
git pull - gets commits from remote
git fetch - downloads remote data


Git Diff:
--------
git diff - shows unstaged changes
git diff --staged - shows staged changes
git diff HEAD - shows all changes since last commit
